## 二、选币逻辑（第一层：收筹池扫描）

### 2.1 扫描频率
- **每日执行一次**（模式 `pool`）
- 遍历币安所有 U 本位永续合约

### 2.2 排除规则
```
排除条件                        | 说明
------------------------------- | ----------------------
稳定币 (USDC/USDP/TUSD/FDUSD)   | 非交易标的
已暴涨 >300%                    | 庄家已经拉盘，来不及上
市值 >$5 亿                    | 空间有限
日均成交 >$2000 万              | 流动性太好，庄家控盘难
```

### 2.3 收筹特征评分（满分 100 分）

| 维度 | 满分 | 评分规则 |
|------|------|---------|
| **横盘天数** | 25 | ≥90天=25分，递减，最低0分 |
| **区间波动** | 20 | 波动<80%=20分，越窄越高 |
| **成交量** | 20 | 成交<$100万=20分，越低越高 |
| **放量启动** | 15 | 当前量/均量≥3x=15分 |
| **预估市值** | 20 | <$5000万=20分，递减 |

### 2.4 状态分类
```
💤 收筹中：未放量，继续等待
⚡ 开始放量：出现成交量异常，关注
🔥 放量启动：进入 OI 异动监控范围
```

## 三、选币逻辑（第二层：OI 异动监控）

### 3.1 扫描频率
- **每小时执行一次**（模式 `oi`）
- 针对已入库的收筹标的池（`watchlist` 表）

### 3.2 OI 异动检测规则
```
触发条件：
  OI 变化 ≥ ±3%  且  当前 OI ≥ $200万
```

### 3.3 三策略评分体系

#### 🔥 追多策略（纯费率排名）
用于强势上涨 + 负费率（多头给空头付钱 = 庄家做多）
```
条件：24h涨幅 >3% 且 费率 < -0.005% 且 成交量 >$100万
评分：按费率从低到高排名
```

#### 📊 综合策略（均衡配置）
| 维度 | 权重 | 规则 |
|------|------|------|
| 费率 | 25 | <-0.5%=25分，递减 |
| 市值 | 25 | <$5000万=25分，递减 |
| 横盘 | 25 | ≥120天=25分，递减 |
| OI变化 | 25 | ≥15%=25分，递减 |

#### 🎯 埋伏策略（低吸等待）
适合还没大涨但有资金悄悄建仓的币
| 维度 | 权重 | 规则 |
|------|------|------|
| 市值 | 35 | <$5000万=35分，递减 |
| OI变化 | 30 | ≥10%=30分，递减 |
| 横盘 | 20 | ≥120天=20分，递减 |
| 费率 | 15 | <-0.1%=15分，递减 |

## 四、入场时机判断（观察器阶段）

### 4.1 入池条件
- 标的已存在于 `watchlist` 且 OI 异动触发
- 系统自动加入 `entry_watchlist`（入场观察池）

### 4.2 支撑/阻力识别
```python
支撑 = max(15m近8根最低价, 5m近12根最低价)
阻力 = 15m近8根（排除最后一根）的最高价
```

### 4.3 入场类型一：回调入场（pullback-entry）

**触发条件（全部满足）：**
```
1. 趋势看多：
   - 价格 > EMA21(15m)
   - EMA9(15m) > EMA21(15m)
   - EMA9 持续向上（最近4根在攀升）
   - 出现更高低点（15m近4根低点 ≥ 15m近5-8根低点）

2. 回调幅度：
   - 距支撑距离 0.8% ~ 3.5%

3. 5m 结构：
   - 当前价 > EMA8(5m) > EMA21(5m)（多头排列）
   - 5m近6根最低价 ≥ 支撑 × 0.998（价格稳在支撑上方）
   - 近期涨幅 ≤ 18%（还没涨太多，还有空间）

4. OI + 费率过滤：
   - OI(1h) > 0 或 OI(6h) > 0（资金在进场）
   - 费率 ≤ 0.015%（不高费率 = 不被多头收割）

5. 交易所规则兼容：
   - 精度兼容
   - 风险可达（能买到足够的量）
```

### 4.4 入场类型二：突破入场（breakout-entry）

**触发条件：**
```
1. 趋势看多（同上）

2. 价格已逼近阻力：
   - 距支撑距离 ≤ 5.5%
   - 当前价 ≥ 阻力 × 0.998（已突破或即将突破）

3. 放量确认：
   - 5m 成交量 ≥ 近20根均值 × 1.35

4. 近期涨幅 ≤ 22%

5. OI + 费率过滤（同上）
```

### 4.5 无法入场的情况

| 状态 | 原因 | 动作 |
|------|------|------|
| `WATCHING/wait-reset` | 涨太多+回调浅 | 等回调或下一轮 |
| `WATCHING/wait-oi-funding` | OI/费率不达标 | 等指标改善 |
| `WATCHING/wait-demo-compatible` | 交易所规则不兼容 | 跳过 |
| `WATCHING/wait-achievable-risk` | 数量规则限制 | 跳过 |
| `INVALIDATED/support-broken` | 支撑已破 | 不再尝试 |

## 五、下单参数计算

### 5.1 风险预算
```
每笔交易风险预算 = $100 USDT
```

### 5.2 仓位计算公式
```
数量 = $100 ÷ (入场价 - 止损价)
杠杆 = 1 ÷ (止损距离% + 1.5%清算缓冲)

示例：
  入场价 = $1.0000
  止损价 = $0.9700
  止损距离 = $0.0300 (3%)
  杠杆 = 1 ÷ (0.03 + 0.015) = 22x

  数量 = 100 ÷ 0.03 = 3,333 个
```

### 5.3 精度处理
```
价格向下取整到 tick_size（如 0.00000001）
数量向下取整到 step_size（如 1）
验证 min_notional ≥ $5
```

### 5.4 信号结构

## 六、信号传递与执行

### 6.1 Webhook 推送
```
雷达 → Webhook → ai-trader
        ↓
   重试 3 次
        ↓
   成功 → 下单
   失败 → 分类处理
```

### 6.2 失败分类与处理

| 错误类型 | 关键词 | 处理 |
|----------|--------|------|
| `invalid-symbol` | Invalid symbol / Invalid symbol status | **立即 INVALIDATED**，停止重试 |
| `position-limit` | Exceeded maximum allowable position | 降低杠杆重试 |
| `insufficient-margin` | Insufficient margin | 等待账户有余额 |
| `rule-mismatch` | precision / lot size / price filter | 调整数量/价格重试 |
| `retryable` | 5xx / 429 / 网络错误 | 等待后重试 |
| `non-retryable` | 其他 | 放弃，保持 READY 供后续重试 |

### 6.3 ai-trader 执行
```
1. 设置杠杆
2. 市价开多
3. 设置止损止盈（止损传入，止盈=1.25x入场价）
4. 取消所有挂单
5. 记录成交结果
```

## 七、仓位监控与离场

### 7.1 监控频率
- **每分钟检查一次**（模式 `manage`）
- 自动同步：`position_watchlist` ↔ 币安实际持仓

### 7.2 自动同步机制
```
观察池有，实际没有 → 标记 CLOSED（手动平仓）
实际有，观察池没有 → 同步加入 ACTIVE（手动开仓）
```

### 7.3 离场决策树

```
                        ┌─────────────────────────┐
                        │  analyze_open_position() │
                        │  (核心分析函数)            │
                        └───────────┬─────────────┘
                                    │
                    ┌───────────────┼───────────────┐
                    ↓               ↓               ↓
            触及硬止损？      试错成本保护？     波段结构分析
                    │               │               │
                    ↓               ↓               ↓
              EXIT              ┌────┴────┐    识别波段高低点
             (立即平仓)         │ 满足条件? │         │
                                └────┬────┘         ↓
                                     ↓          下跌/上涨比≥40%？
                                     ↓YES             │
                              EXIT (提前离场)         ↓YES
                                                EXIT (强下跌出场)
                                     ↓NO              │
                              继续检查...        检查动态止损线
                                              │
                                              ↓
                                    跌破波段低点？
                                              │
                                              ↓YES
                                        EXIT (波段止损)
```

### 7.4 波段结构分析（核心创新）

#### 波段识别算法
```python
1. 找出所有波段低点和波段高点
   - 波段低点：前后2根K线都更低
   - 波段高点：前后2根K线都更高

2. 计算波段幅度
   - 上一上涨波段 = (最近高点 - 次低点) / 次低点
   - 当前下跌波段 = (最近高点 - 当前价) / 最近高点

3. 计算比值 = 下跌 / 上涨
   - 比值 ≥ 40% = 强下跌信号 → 立即出场
   - 比值 < 40% = 正常回调 → 继续持有
```

#### 波段示例
```
入场后走势：
  1.000 → 1.080 → 1.050 → 1.100 → 1.070 → 1.090

波段分析：
  上涨波段：1.000 → 1.080 = +8.0%
  下跌波段：1.080 → 1.050 = -2.8%
  比值：2.8 / 8.0 = 0.35 (35%) < 40% → HOLD ✓

后续走势：1.090 → 1.040
  新下跌波段：1.090 → 1.040 = -4.6%
  比值：4.6 / 8.0 = 0.575 (57.5%) > 40% → EXIT ✓
```

### 7.5 动态止损线

```
止损线跟随规则：

阶段1：无盈利
  止损线 = 波段低点 × 0.998
  （最低不低于入场价，除非已盈利）

阶段2：盈利 ≥ 1%
  止损线 = max(波段低点, 入场价 × 0.998)

阶段3：盈利 ≥ 2.5%
  止损线 = max(波段低点, 入场价 × 1.001)

阶段4：盈利 ≥ 5%
  止损线 = max(波段低点, 入场价 × 1.005)

高盈利额外保护（ROI 利润率保护）：
  - 峰值利润 ROI ≥ 2x → 锁 50% 收益
  - 峰值利润 ≥ $300 或涨幅 ≥ 5.5% → 锁 60% 收益
  - 峰值利润 ≥ $600 或涨幅 ≥ 10% → 锁 70% 收益
```

### 7.6 试错成本保护（妖币专用）

对于高杠杆（>20x）的仓位，若浮亏接近风险预算的一半且 K 线出现多个走坏信号，提前离场：
```python
触发条件：浮亏 ≥ $50（或风险预算×50%，取较大值）
         +
         满足以下至少 3 项：
         - 近3根5m K线都是阴线
         - 价格跌破近8根5m最低点
         - EMA8 < EMA21（空头排列）
         - 价格无法收复 EMA8
         - 卖方量能放大
         - OI 下降或空头压力
```

### 7.7 其他离场条件

| 条件 | 描述 | 动作 |
|------|------|------|
| 硬止损 | 价格 ≤ 固定止损价 | EXIT |
| 波段止损 | 跌破动态止损线 | EXIT |
| 强下跌波段 | 下跌/上涨比 ≥ 40% | EXIT |
| 趋势破位 | 跌破 EMA21(5m) + EMA21(15m) + 近5根低点 | EXIT |
| 空头积聚 | OI增+价格跌+趋势破位 | EXIT |
| 燃料衰竭 | 涨幅≥8% + 费率>0.025% + OI下降 | EXIT |
| 利润回吐 | 峰值利润回吐50% + 已有盈利 | EXIT |
| 深度回撤 | 峰值回撤≥18% + 在下跌波段中 + 涨幅≥4% | EXIT |
| 趋势预警 | 趋势破位但未确认 | WATCH |

## 九、数据库表结构

### 9.1 watchlist（收筹标的池）
```sql
symbol, coin, status, score, sideways_days, range_pct, avg_vol, ...
```
用途：每日收筹扫描结果，OI 异动监控对象池

### 9.2 entry_watchlist（入场观察池）
```sql
symbol, watch_status, setup_type, support_price, resistance_price,
suggested_entry, suggested_stop, trigger_signal, notes, ...
```
用途：观察入场时机，等待 READY 状态

| watch_status | 说明 |
|--------------|------|
| WATCHING | 观察中，不满足入场条件 |
| READY | 满足条件，等待下单 |
| TRIGGERED | 信号已发送 |
| EXECUTED | 已成交 |
| INVALIDATED | 不可交易，跳过 |

### 9.3 position_watchlist（持仓观察池）
```sql
symbol, side, entry_price, stop_price, quantity, leverage,
status, peak_price, guard_price, exit_signal, exit_reason, ...
```
用途：监控已开仓位，判断离场时机

| status | 说明 |
|--------|------|
| ACTIVE | 持仓中，持续监控 |
| EXIT | 触发离场条件 |
| CLOSED | 已平仓 |

### 9.4 market_snapshots（市场快照）
```sql
symbol, price, oi_usd, oi_d1h_pct, oi_d6h_pct, funding_rate, ...
```
用途：历史市场数据，用于回溯和评分
